# .github
OpenTX Companion — настольная программа для настройки радиопередатчиков с прошивкой OpenTX. Позволяет создавать и редактировать модели, резервировать настройки EEPROM, управлять профилями передатчика, устанавливать и обновлять OpenTX, а также использовать симулятор для проверки конфигурации управления.
