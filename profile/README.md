## Обзор проекта

**OpenTX Companion** — официальное настольное приложение экосистемы **OpenTX**, предназначенное для работы с настройками совместимых RC-передатчиков. Программа позволяет редактировать конфигурацию моделей на компьютере, создавать резервные копии и переносить подготовленные настройки на аппаратуру.

Companion значительно упрощает работу со сложными конфигурациями радиоуправления. На большом экране удобнее настраивать Inputs, Mixes, Outputs, логические переключатели, специальные функции и другие элементы модели, чем непосредственно через меню передатчика.

Программа также используется для работы с прошивкой OpenTX. Пользователь может подготовить подходящую сборку firmware для совместимой аппаратуры и выполнить необходимые операции обновления. Перед любыми изменениями рекомендуется сохранить существующие модели и настройки передатчика.

## Модели, микшеры и резервные копии

Каждая модель может содержать собственную структуру входов, микшеров, каналов, переключателей и специальных функций. Companion предоставляет графический интерфейс для изменения этих параметров и помогает организовать конфигурацию передатчика без постоянного редактирования через его небольшой экран.

Для сложных RC-моделей особенно важны **Mixes** и **Logical Switches**. С их помощью можно создавать зависимости между органами управления, переключателями и выходными каналами, а также реализовывать дополнительные сценарии управления.

Перед обновлением прошивки или серьёзным изменением конфигурации рекомендуется создавать резервную копию. Это позволяет восстановить модели и настройки, если новая конфигурация окажется неправильной или потребуется вернуться к предыдущему состоянию.

| Компонент | Поддержка |
|---|---|
| **Прошивка** | OpenTX |
| **FrSky Taranis** | Поддерживаемые OpenTX модели |
| **FrSky Horus** | Совместимые передатчики и версии OpenTX |
| **RadioMaster** | Модели, использующие совместимые версии OpenTX |
| **Jumper** | Совместимые OpenTX-передатчики |
| **EEPROM / Settings** | Резервирование и редактирование конфигураций |
| **USB** | Используется поддерживаемыми передатчиками для подключения |
| **Windows** | Поддерживаемые версии Companion |
| **macOS / Linux** | Доступность зависит от версии приложения |

Необходимо выбирать версию OpenTX и параметры сборки именно для конкретной модели передатчика. Прошивка от другой аппаратной платформы может быть несовместима с устройством.

Для более новых передатчиков также следует учитывать, что часть RC-экосистемы перешла на **EdgeTX**. OpenTX Companion предназначен прежде всего для аппаратуры и конфигураций, использующих OpenTX.

## Прошивка и симуляция

Companion позволяет работать с firmware OpenTX без необходимости выполнять все операции непосредственно через меню передатчика. При подготовке прошивки важно правильно выбрать целевую модель аппаратуры и необходимые параметры сборки.

Встроенные средства симуляции позволяют проверить поведение подготовленной модели до переноса конфигурации на реальный передатчик. Можно проверить положение каналов, работу переключателей, микшеров и логических функций.

Симуляция не заменяет окончательную проверку на реальной аппаратуре. После записи конфигурации необходимо убедиться, что каналы, направления, диапазоны и Failsafe соответствуют требованиям конкретной модели.

## Быстрый старт

1. Запустите **OpenTX Companion**.
2. Создайте профиль для своего RC-передатчика.
3. Укажите правильную модель аппаратуры и параметры OpenTX.
4. Подключите передатчик к компьютеру при необходимости.
5. Сохраните резервную копию существующей конфигурации.
6. Откройте или создайте необходимую модель.
7. Настройте Inputs, Mixes, Outputs и переключатели.
8. Проверьте конфигурацию через симулятор.
9. Перенесите подготовленные настройки на передатчик.
10. Перед использованием модели проверьте все каналы и функции на реальной аппаратуре.
